# Детоксинг 10 · Лендинг

Одностраничный лендинг программы «Детоксинг 10» клиники Bisharova Clinic.

Все ресурсы (фото, шрифты подключаются с Google Fonts) встроены в `index.html` — отдельных файлов с картинками нет, файл работает как самодостаточный.

## 🚀 Как опубликовать на GitHub Pages — 7 шагов

### Шаг 1. Создайте аккаунт GitHub (если ещё нет)

Зайдите на [github.com](https://github.com) и зарегистрируйтесь. Запомните username — он будет в адресе сайта.

### Шаг 2. Создайте новый репозиторий

1. Войдите в GitHub
2. В правом верхнем углу нажмите **+** → **New repository**
3. Введите имя репозитория, например: `detoxing-10`
4. Выберите **Public** (для GitHub Pages бесплатно нужен публичный репозиторий)
5. **НЕ** ставьте галочки на «Add a README file», «Add .gitignore» и т.д.
6. Нажмите **Create repository**

### Шаг 3. Загрузите файлы

На странице нового репозитория увидите ссылку **«uploading an existing file»** — нажмите её.

Перетащите в окно браузера **оба файла** из этой папки:
- `index.html`
- `README.md`

Внизу страницы нажмите **Commit changes** (зелёная кнопка).

### Шаг 4. Включите GitHub Pages

1. В вашем репозитории откройте вкладку **Settings** (вверху справа)
2. В левом меню найдите раздел **Pages**
3. В блоке **Build and deployment** под надписью **Source** выберите: **Deploy from a branch**
4. Под **Branch** выберите: `main` (или `master`) и папку `/ (root)`
5. Нажмите **Save**

### Шаг 5. Подождите 1–2 минуты

GitHub соберёт сайт. Обновите страницу Settings → Pages — в верхней части появится зелёный блок с надписью:

> ✅ **Your site is live at https://ваш-username.github.io/detoxing-10/**

### Шаг 6. Откройте ссылку и проверьте

Скопируйте ссылку и откройте в новой вкладке. Если всё ок — лендинг работает и доступен в интернете 24/7.

### Шаг 7. Готово — можно делиться

Эту ссылку можно:
- Отправлять клиентам
- Размещать в Instagram, Telegram, WhatsApp
- Сохранить в закладки
- Использовать в email-подписях

## 🔧 Как внести правки

### Простой способ — через GitHub в браузере

1. Откройте свой репозиторий
2. Нажмите на файл `index.html`
3. Нажмите иконку карандаша 🖊 (Edit this file)
4. Внесите изменения
5. Внизу страницы нажмите **Commit changes**
6. Через 1–2 минуты изменения появятся на сайте

### Локально на компьютере

1. Скачайте файл `index.html` себе на компьютер
2. Откройте его в редакторе (даже Блокнот подойдёт, но лучше [VS Code](https://code.visualstudio.com))
3. Внесите правки
4. Загрузите обратно в репозиторий (Add file → Upload files)

## 📷 Как заменить фото

Фото вставлены в HTML как base64-данные. Чтобы заменить:

1. Откройте новое фото на [компрессоре](https://squoosh.app) и сожмите до 1400px по длинной стороне
2. Сконвертируйте в base64 на [base64.guru/converter/encode/image](https://base64.guru/converter/encode/image)
3. Скопируйте получившуюся строку (начинается с `data:image/jpeg;base64,...`)
4. В `index.html` найдите нужное фото (поиск по `src="data:image/jpeg;base64,`) и замените строку целиком

**Намного проще** — попросите меня в следующем чате: «замени фото X на это», и я пересоберу файл с новым фото.

## 🌐 Подключение своего домена (опционально)

Если у вас есть домен (например, `bisharova-clinic.ru`):

1. В Settings → Pages в поле **Custom domain** введите ваш домен
2. У регистратора домена настройте DNS-запись: тип `CNAME`, значение `ваш-username.github.io`
3. Дождитесь распространения DNS (от 10 минут до суток)

## ⚠️ Важно перед запуском рекламы

Перед тем как давать ссылку в платную рекламу (Яндекс.Директ, Google Ads, Meta), рекомендуется:

1. **Показать тексты юристу по медицинской рекламе** — реклама медуслуг в РФ регулируется ФЗ-38 ст. 24 и требует особых формулировок
2. **Проверить наличие медицинской лицензии клиники** — её данные обычно публикуются в подвале сайта
3. **Добавить блок политики обработки персональных данных** — обязателен по 152-ФЗ при сборе телефонов и имён через форму
4. **Настроить реальный приём заявок** — сейчас форма показывает alert, нужно подключить отправку (например, через [Formspree](https://formspree.io) или [Getform](https://getform.io) — оба бесплатно для небольших объёмов)
